# Emergence — feedback-002 play guide

Start a new market run for this feedback build; old saves retain earlier encounter state. Try the market for about ten minutes. Your first goal is to reach transit at the back of the market. Ilan in the repair shop may be able to help. Explore, talk, and try things that seem physically plausible. You can keep exploring after reaching an exit.

## Controls

| Action | Control |
|---|---|
| Move / look | WASD / mouse |
| Sprint / crouch / jump | Shift / Ctrl / Space |
| Use, pick up, set down | E |
| Hands / pistol / prod / service tool | 1 / 2 / 3 / 4 |
| Fire, throw a held object, hold to service | Left mouse button |
| Drop a held object | Right mouse button |
| Reload pistol | R |
| Save / load | F5 / F9, or pause-menu buttons |
| Pause and release the mouse | Escape |

Click **Enter the market** to start. The game waits for your explicit start/resume before capturing the mouse. On Mac, function keys may require Fn. There are no autosaves; use F5 before trying something risky.

## Launch

Extract the entire ZIP. Open Emergence.app on Mac, or Emergence.exe on Windows. Keep Windows package files together.

The Mac app is ad-hoc signed, but not Apple-notarized. If blocked, first try opening it, then use System Settings → Privacy & Security → Open Anyway if you trust the download. Apple explains this app-specific exception here: https://support.apple.com/en-gb/102445

The Windows build is unsigned and has not yet been played on Windows. Please report launch or graphics problems with your Windows version and GPU model.
